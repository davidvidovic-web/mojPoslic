# Security Measures

Your safety is our priority. On mojPoslić platform, we have implemented numerous measures so you can safely post and complete jobs.

## Our security measures

### User Verification
- **Email verification** - required for all users
- **Phone verification** - SMS verification
- **Document verification** - for increased trust
- **Social media** - profile linking

### Secure Payments
- **Escrow system** - money is held until job completion
- **Encryption** - all payment data is encrypted
- **PCI DSS** - compliance with international standards
- **Refunds** - protected money returns

### Platform Monitoring
- **24/7 monitoring** - continuous activity surveillance
- **AI detection** - automatic detection of suspicious activities
- **User reports** - quick response to reports
- **Moderation team** - professional security team

## 🔒 How to stay safe

### For clients:

#### ✅ Good tips:
- **Check ratings** of taskers before hiring
- **Communicate through platform** - use our chat system
- **Set clear expectations** in job description
- **Pay through platform** - never outside the system
- **Request work proof** - photos, confirmations

#### ❌ What to avoid:
- Payment outside platform
- Sharing personal information too early
- Hiring without verified ratings
- Refusing to use chat system
- Accepting suspicious requests

### For taskers:

#### ✅ Good tips:
- **Verify your profile** completely
- **Communicate professionally** always
- **Request clear instructions** from client
- **Document work** with photos
- **Report suspicious activities** immediately

#### ❌ What to avoid:
- Working without clear agreement
- Accepting payment outside platform
- Sharing private information
- Working without safety equipment
- Agreeing to inappropriate requests

## Recognizing scams

### Common scams:

#### 1. Payment fraud
**Signs:**
- Request for payment outside platform
- "Urgent" jobs with excessive prices
- Requests for bank details
- Poor grammar in messages

**What to do:**
- Report the user
- Don't share bank details
- Use only platform for payment

#### 2. Fake jobs
**Signs:**
- Unclear job description
- Unrealistically high budget
- Urgency without reason
- Strange locations or addresses

**What to do:**
- Ask clarifying questions
- Request additional information
- Trust your intuition

#### 3. Misrepresentation
**Signs:**
- Photos that don't match description
- Inconsistent information
- Refusing video calls
- Suspicious profiles without ratings

**What to do:**
- Check all details carefully
- Use video calls for verification
- Report suspicious profiles

## 🔧 Job site safety

### For physical jobs:

#### Before starting:
- Inform someone about your location
- Check address in advance
- Arrange communication method
- Bring necessary safety equipment

#### During work:
- Follow safety measures
- Document progress
- Communicate regularly with client
- Report any problems

#### After completion:
- Complete job through platform
- Leave feedback
- Save work evidence
- Request rating

### For online jobs:

#### Data protection:
- Use secure connections (VPN)
- Don't share passwords or access
- Backup important files
- Use antivirus software

#### Communication:
- Use professional email addresses
- Document all agreements
- Set clear deadlines
- Communicate through platform

## 📞 Reporting problems

### When to report:
- Suspicious activities
- Inappropriate behavior
- Fraud attempts
- Platform rule violations
- Security incidents

### How to report:
1. **Chat support** - immediate help
2. **Email support** - detailed reports
3. **Phone** - emergency cases
4. **User report** - directly from profile

### What to include in report:
- Detailed problem description
- Screenshots if possible
- Names of involved users
- Date and time of incident
- Any evidence you have
