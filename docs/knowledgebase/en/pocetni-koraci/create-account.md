# How to create an account

Creating an account on mojPoslić platform is quick and simple. Follow these steps for successful registration.

## Step 1: Go to registration page

Click on **"Register"** in the top right corner or go directly to [/en/auth/register](/en/auth/register).

## Step 2: Choose account type

### 👤 Client
- For those who need help with jobs
- You can post jobs
- You're looking for services from others

### Tasker
- For those who want to earn money
- You can apply to jobs
- You offer your services

### 🏢 Company
- For businesses and professionals
- You can post and apply
- Business profile with additional features

> **Note**: You can change account type later in settings.

## Step 3: Enter basic information

You'll need to enter:

- **Email address** - For login and communication
- **Password** - Minimum 8 characters
- **First and last name** - Your real name
- **Phone** - For verification and communication

## Step 4: Email verification

1. Check your email inbox
2. Click the link in the message
3. Your account will be activated

## Step 5: Profile setup

### For clients:
- Add short description about yourself
- Enter location
- Set profile picture

### For taskers:
- Describe your skills
- List work experience
- Set working hours
- Determine service prices

### For companies:
- Add company information
- Upload logo
- List certificates/licenses
- Set business hours

## Step 6: Identity verification (recommended)

For increased security and trust:

- **Upload ID document photo**
- **Verify phone with SMS code**
- **Add social media profiles**

## Step 7: Payment settings

### For clients:
- Add credit/debit card
- Set default payment method

### For taskers:
- Add bank account for payouts
- Set accepted currencies

## Security tips

### ✅ Good practices:
- Use strong password
- Verify all information
- Add profile picture

### ❌ Avoid:
- Sharing password
- False information
- Accepting suspicious offers

## Common issues

### Not receiving verification email
1. Check spam folder
2. Verify email address is correct
3. Request new link

### Forgot password
1. Click "Forgot password?"
2. Enter email address
3. Follow instructions in email

### Phone verification problems
1. Check if number is correct
2. Wait 1-2 minutes for SMS
3. Request new code
